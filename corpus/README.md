# corpus/ 通用回归语料

语料切割线（与 bobachop corpus 同一策略，DESIGN §8/§13）：

- **形态类语料（本目录，进公开仓）**：按行业典型分片/加密/分区形态构造的合成 SQL——
  合成命名（`t_order` / `ds_0` 一类通用形态）、无真实字面量、不派生自任何真实系统。
  每文件一行一条语句，`--` 注释行跳过（内核 corpus 同一约定）。
- **生产实例语料（永不进本仓）**：真实捕获的生产流量（真实 schema + 字面量）只进内网
  `corpus-internal/`（gitignored），跑决策链回放（DESIGN §9 关1）。

目录按用途组织（T4 回放工具落地后补充约定）：

- `sharding/` —— 分片路由与归并形态（单分片 / 跨分片 / 广播 / 绑定表）
- `encrypt/` —— 加密改写形态（M3，对拍存量 encrypt 测试语料的合成等价类在仓内）
- `partition/` —— D13 分区定位形态（定位成功 / miss 回退 / 多行跨分区）
